# Raíz

Tu vida es un árbol. Cada hábito le da savia.

Raíz es una web app para formar hábitos como si fuera un juego: cumplís misiones reales,
ganás savia, tu árbol crece de semilla a bosque, y la app te acompaña en los días buenos y en los malos.

- Las reglas del juego están en [REGLAS.md](REGLAS.md).
- Se instala en el iPhone desde Safari: Compartir → Agregar a inicio.
